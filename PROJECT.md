# Luke Gagliardi / Software Laboratory

The homepage is a launchpad for Luke's software, artist websites, institutional prototypes, presentations and experiments. A compact selection introduces the work. The project index supports browsing the full catalogue, finding a known project and discovering related work by topic.

## Scope

- Serve the public collection at the root of lukegagliardi.com. Preserve CNAME and existing subproject URLs.
- Carry forward the 22 projects displayed on the preceding homepage and add Nodeboard as approved public work. Source links and launches are independent. Three approved projects retain launch-only visibility.
- Treat approved HTTP destinations as launch experiences. The source update view uses verified public commits, with no claim about which version is running in production.
- Use screenshots from approved public project views. Institutional descriptions stay concise. The AI@YORK spotlight shows only the public demo task checker.
- Target WCAG 2.2 AA across keyboard, touch and reduced-motion browsing.

## Acceptance

A visitor can launch a project directly from its feature or whole index row, open approved source separately, intersect search with category and topic, switch to selected work or recent updates, and reset. The complete index and launch links remain usable without JavaScript. The local site should render at 320px through wide desktop with no horizontal overflow or failed initial resources.

See [ARCHITECTURE.md](ARCHITECTURE.md) for local setup and publishing a project record, and [DESIGN.md](DESIGN.md) for composition and evidence.
